# 2 Pro 遥控器麦克风

语音通过独立 BLE ATVV 通道进入程序，按键继续走原来的 HID 映射。
仅支持真实识别为 RC003 的 2 Pro。C2 与其他遥控器保留按键能力。

## 使用

1. 安装外部依赖 [BlackHole 2ch](https://existential.audio/blackhole/)。安装程序需要管理员授权；系统提示重启时按提示操作。
2. 在映射程序选中系统已配对的 2 Pro。
3. 控制面板或菜单栏打开“遥控器麦克风…”，刷新设备，选择 BlackHole 2ch，勾选启用。
4. 推荐启用“自动切换麦克风”，系统输入先选电脑麦克风，豆包选择“自动检测”。遥控器 Fn 按下前临时切换输入至 BlackHole，延迟 250 ms 发送 Fn；松开后延迟 600 ms 恢复原输入。普通键盘 Fn 不触发切换。关闭自动模式时，豆包手动选择 BlackHole 2ch。保留真实扬声器为系统输出。
5. 保留语音键的 Fn 映射，按住语音键说话，松开停止。窗口的音频包与电平反映遥控器来源，不代表豆包已经收到或完成识别。

若豆包版本未显示 BlackHole，需检查它的麦克风选择界面；当前实现不能保证每个版本接纳虚拟音频设备。

## 边界与隐私

默认关闭。仅在用户启用后建立语音连接。程序不采集 Mac 麦克风，不保存或上传声音。自动模式临时修改系统默认输入，保存原设备 UID，在松键、停止、睡眠或下次启动时恢复；不修改系统输出。如果用户在录音期间另选了输入设备，不覆盖该选择。解码后的 16 kHz 单声道 PCM 只送入用户选择的回环设备；下游输入法如何处理声音由其自身策略决定。

自动模式影响同时使用系统默认输入的其他应用，会议期间建议关闭。不要同时按住电脑 Fn 和遥控器语音键。豆包是否及时跟随系统输入切换需要真机验收，自动切换已执行不等于转文字成功。

标准 ATVV 服务 `AB5E0001…` 的能力协商之后，接受 RC003 的直接 `04 → audio → 00` 会话；也支持遥控器 `08` 请求开麦。能力仅接受 v1 和 16 kHz，处理 2671 固件已公开的能力字节布局兼容。IMA/DVI ADPCM 按高 nibble 优先解码，跨通知拼帧，同步包重置 predictor/index，结束和重连清理状态。

输出队列限制为两秒；松键后等待已排队音频播放，避免丢掉句尾。使用输入禁用的 AUHAL 固定绑定虚拟输出设备，每次写入前验证实际设备，不使用随默认设备切换的 AVAudioEngine，防止声音被转到扬声器。16 kHz 单声道线性插值至设备采样率，复制到输出各声道。断线、睡眠、换设备和关闭功能立即清理音频；连接失败延迟重试，音频中断三秒则重连。

BlackHole 为独立安装的外部程序。本项目没有包含或修改其驱动源码；本项目 MIT 协议保持不变。

## 验证

自动检查：`./scripts/check.sh`，包含已知 ADPCM 向量、分片、直接语音流、停止、第二次会话和不兼容编码。

安装回环设备后，可运行 `--test-voice-output-route` 静音硬件回归测试：开始固定输出，切换默认输入再恢复，验证输出始终绑定指定回环设备。测试不采集麦克风，结束时恢复原输入。

真机验收需要完成：遥控器持续收包、电平变化、BlackHole 下游收音、豆包出字，以及第二次长按、睡眠重连。只有全部通过才能称为端到端可用。
